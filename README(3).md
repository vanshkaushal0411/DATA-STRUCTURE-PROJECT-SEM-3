# AlgoSpace – Algorithm Visualization Lab

## Project Overview

AlgoSpace is an interactive web-based learning project designed to help students understand common sorting and pathfinding algorithms through visual animations.

The project is built using HTML5, CSS3, and JavaScript.

## Main Features

### Sorting Lab
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Adjustable array size and animation speed

### Pathfinding Lab
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Interactive grid visualization

## Technologies Used

- **HTML5** – structure and interface
- **CSS3** – layout, styling, responsive design, animations
- **JavaScript** – algorithm logic, visualization, controls, and user interaction

## How to Run

1. Extract the project folder.
2. Open the folder.
3. Double-click `index.html`.
4. The website will open in a modern web browser.
5. Select an algorithm and start the visualization.

No server or additional software is required.

## How to Use

### Sorting Lab
1. Open the Sorting Lab.
2. Select a sorting algorithm.
3. Adjust the array size and animation speed if required.
4. Start the visualization.
5. Observe how the elements are compared and rearranged.

### Pathfinding Lab
1. Open the Pathfinding Lab.
2. Select BFS or DFS.
3. Generate or reset the grid.
4. Start the visualization.
5. Observe how the algorithm explores the grid and finds a path.

## Learning Objective

The main objective of AlgoSpace is to make algorithms easier to understand by combining theoretical concepts with visual demonstrations. It helps students understand algorithm execution, traversal, comparisons, and efficiency.
